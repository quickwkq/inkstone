# 0.3.1 编辑器样式

参考成熟产品的写作体验，不宣称存在跨平台统一的“好评最多”排名，也不复制其专有素材或样式源码。

- [Typora](https://typora.io/)：减少编辑标记和界面对正文的干扰。
- [Bear](https://bear.app/)：简洁的侧栏、清晰的字体层级和轻量界面。
- [Obsidian](https://obsidian.md/help/appearance)：兼顾明暗主题和编辑、阅读场景。

正文使用本机字体，默认 16px / 1.75 行高，最大正文宽度约 720px。一级标题 30px、二级 23px、三级 19px。段落间距 0.85em，引用使用单条细竖线，代码保持等宽字体并在自身区域内横向滚动。

界面使用 232px 侧栏、56px 文件栏、44px 模式栏、28px 状态栏。保留低饱和绿色作为操作和选中状态，避免大片强调色。深色主题使用独立颜色变量；键盘焦点仍清晰可见。

即时编辑和阅读共用 src/document.css，源码保留等宽字体。修正容器最小宽度与长文本换行；标题旁 H1/H2 辅助标记仅在悬停时出现，正在编辑的 Markdown 标记保持可用。专注模式隐藏格式工具栏。

验收覆盖 1280/760/600px 三种宽度、即时编辑/源码/阅读、长中文和长 URL、明暗主题。样式不改写文档内容，也不会恢复文档中已经丢失的图片。
