# 墨页 Inkstone

一个安静、轻量的 macOS Markdown 阅读编辑器。无需注册，无需安装开发工具。

## 下载

[前往 Releases 下载最新版](https://github.com/quickwkq/inkstone-releases/releases)

| 你的 Mac | 选择的安装包 |
| --- | --- |
| Apple Silicon（M 系列芯片） | 文件名含 `mac-arm64.dmg` |
| Intel Mac | 文件名含 `mac-x64.dmg` |

在「 → 关于本机」查看芯片类型。系统要求：macOS 13 或更高版本。Intel 安装包已交叉构建，尚未在真实 Intel Mac 上验收。

## 安装

1. 下载对应的 DMG，双击打开。
2. 将 **Inkstone** 拖到 **Applications（应用程序）**。
3. 从应用程序文件夹启动 Inkstone，再推出安装磁盘。

**当前版本为未签名、未公证测试版。** 首次打开可能出现无法验证开发者的提示。如确认下载来源是本仓库且文件未被篡改，可按 [Apple 官方说明](https://support.apple.com/en-us/102445)，在「系统设置 → 隐私与安全性」查看该应用的“仍要打开”选项。企业管理的 Mac 可能不允许此操作。不要关闭系统安全保护。

每个版本附带 SHA256SUMS.txt，可验证下载文件的完整性。校验和不等于 Apple 签名或公证。

## 功能

- 即时 Markdown 编辑、源码、阅读模式
- 标题大纲、文档搜索、当前文档查找、明暗主题、专注模式
- 本地草稿恢复、文件保存和另存为
- 最近文件、Finder「打开方式」和拖入 Dock 打开 Markdown
- 外部修改检测，避免静默覆盖其他程序的修改
- HTML 导出、打印 / PDF

⌘N 新建 · ⌘O 打开 · ⌘S 保存 · ⇧⌘S 另存为 · ⌘W 关闭文档 · ⌘F 查找。

文档上限 10 MB。草稿自动保存到本机，写入 .md 文件需要点击保存或按 ⌘S。富文本编辑会规范化 Markdown 格式，不承诺字节级往返。尚不支持云同步、版本历史和自动更新。外部图片需要网络。

## 更新与反馈

退出旧版，安装新版并覆盖应用程序文件夹中的 Inkstone，通常会保留本机草稿。升级前建议把重要文档保存为 .md 并备份。

本仓库用于分发安装包、发布说明及问题反馈；源码仓库保持私有，当前不以开源项目发布。第三方组件遵循各自许可证，应用包包含相应依赖许可。
